# 三、国内外研究现状与研究缺口（完整起草）

## 3.1 面板政策评估的两条路线

评估一项干预对面板单位的平均效应，常用的两类方法是双重差分（DID）与合成控制（SC）。DID 依赖平行趋势假设，而这一假设在原始数据中常常不成立；SC 通过对对照单位重新加权，使加权对照组在处理前的走势与处理组匹配，但通常只用于极少数处理单位，且回归中不含单位固定效应 [§1]。两者长期被视为适用场景不同的工具；Arkhangelsky 等人认为二者背后的假设其实很接近 [§1]。

## 3.2 合成双重差分（SDID）

SDID 把两条路线放进同一个加权的双向固定效应回归（Eq. 1.1）：单位权重 $\hat\omega_i$ 与时间权重 $\hat\lambda_t$ 作为回归权重，使比较集中在与处理组相像的单位和时期上 [Eq. 1.1, §1]。在这一表述下，DID 是不加权的特例（Eq. 1.2），SC 则是去掉单位固定效应与时间权重的特例（Eq. 1.3）。

两组权重各有分工。单位权重由带 $\ell_2$ 正则的 Eq. 2.1 求得，并带截距 $\omega_0$，因此只要求加权对照组在处理前与处理组**平行**，而不要求重合；常数差由单位固定效应吸收，正则参数 ζ 按 Eq. 2.2 选取 [§2.1]。时间权重由不带正则的 Eq. 2.3 求得，只在处理前时期之间分配，处理后各期权重固定相等 [Eq. 2.3]。作者指出，只要两组权重之一平衡得好，系统成分的影响就近似被消掉，称之为一种双重稳健性 [§4]；这一性质依赖低秩因子结构 $L$ [Eq. 4.1]、噪声序列相关不太强和因子跨期稳定等条件 [§4]。推断方面，原文给出 bootstrap、jackknife 与 placebo 三种方差估计 [§5, Algorithm 2–4]，其中 jackknife 在只有一个处理单位时无定义，placebo 法依赖单位之间同方差 [§5]。

经验证据来自一个案例和两组校准模拟。在加州控烟案例中，SDID 的估计为 −15.6（标准误 8.4），DID 为 −27.3（17.7），SC 为 −19.6（9.9）[Table 1]。在以 CPS 校准的零效应安慰剂模拟中，基线设定下 SDID 的 RMSE 为 0.028，SC 为 0.037，DID 为 0.049 [Table 2]；在以 PWT 校准的模拟中，Democracy 设定下分别为 0.031、0.038 与 0.197 [Table 3]。但优势并非无条件：结果模型中去掉交互项时，DID 的 RMSE（0.014）略低于 SDID（0.016）[Table 2, “No M” 行]；作者也承认，系统异质性小时，不等权可能降低精度 [§1]。

## 3.3 SDID 的适用边界

本研究关注原文设定中的三条边界。

第一，**处理同时开始**。原文的目标量 τ 定义为处理组在处理后各期的平均效应，且所有处理单位在同一时刻开始处理（block assignment）[Eq. 4.2 及其前的定义]。在本报告阅读的范围内（§1–§4.1 细读，§4.3 转写，§5 部分），未见交错开始处理的处理办法 [待查: 正式发表版本的附录与作者后续工作是否已覆盖交错采纳]。

第二，**分配不依赖噪声**。原文允许处理分配依赖单位固定效应与交互结构，但要求与误差 $E$ 独立 [Eq. 3.5]；而原文模拟中的分配也只依赖 $L$、不依赖 $E$ [Eq. 3.5]，因此模拟没有检验这一条件被违反时的表现（补）。作者也提到需要借助历史背景排除同期其他冲击 [§4]。

第三，**零效应评估**。两组模拟都是零效应安慰剂设计 [Table 2–3]，异质处理效应下的偏差没有直接检验（补）。

## 3.4 交错采纳与软件工程面板

软件工程实证研究经常需要评估工具或流程改动的效果，例如持续集成、代码评审机器人或依赖更新工具的引入 [待查: 各类工具采纳效果研究的代表文献]，此类问题常用 DID 或回归不连续设计 [待查]。仓库采纳这类工具的时间天然交错，且采纳仓库数量可能多于 SC 通常适用的极少数处理单位（补）。经济学文献对交错采纳下的 DID 已有专门讨论 [待查: 交错 DID 的代表文献，需检索核实，不凭记忆引用]；这些方法是否与 SDID 的加权思路结合、结合后在 SE 面板上表现如何，需要在 M0 检索中确认 [待查]。

综合以上，本研究要填补的缺口有三点，均限定在本报告已检索、已阅读的范围内：
