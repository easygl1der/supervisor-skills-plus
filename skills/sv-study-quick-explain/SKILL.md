# sv-study-quick-explain

Concept mode of the former `study`. Load
`../sv-study/references/procedure.md`, follow its Step 0 (vault and
profile; no material needed), then run the protocol once for the concept.

| Need | Load |
|---|---|
| The round, steps 0 to 10 | `protocol.md` |
| Diagnosing the restatement | `diagnosis.md` |
| Profile and knowledge levels | `learner-profile.md` |
| Saving the session | `session-save.md` |
