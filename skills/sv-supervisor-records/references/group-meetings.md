# Group-meeting records

`sv-slides` is the author of the deck. This skill only stores it.

## Files

- `docs/log/<YYYY-MM-DD>-group-meeting.md`: what was reported, decisions,
  and next steps (the load list for the next weekly report).
- `docs/meetings/<YYYY-MM-DD>/`: `slides.tex`, `slides.pdf`, `notes.md`.

Template: `research-core` `assets/templates/group-meeting-log.md`.

## Rules

- Next steps come from the approved outline or the spoken close, not from
  a reconstructed memory of the meeting.
- STATUS still holds only current state; history stays in the log.
- Linear: one issue per next-step item only if Linear is enabled, linking
  back to the log. Never paste the deck into Linear.
