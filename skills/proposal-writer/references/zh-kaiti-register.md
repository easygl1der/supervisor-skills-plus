# Chinese kaiti register (sentence patterns)

Inspired by common mainland thesis-proposal (kaiti) practice and the
user's textbook context. Principles and bilingual frames only. Do not
paste copyrighted textbook prose. The school's template and review form
always win; never invent word counts or required headings.

## Contents

1. Problem first (选题依据)
2. Gap-organized literature (研究现状)
3. Numbered innovation points (创新点)
4. Technical roadmap
5. Milestones as deliverables
6. What not to write

## 1. Problem first (选题依据)

Lead with the phenomenon or decision that is blocked, then why current
tools fail, then why now. Do not open with a century of field history.

| Avoid | Prefer |
|---|---|
| "X has been widely studied and is of great theoretical and practical significance." | "Setting S needs quantity Q; current estimators assume A, which S violates because B." |
| 该领域历史悠久，具有重要理论与实践意义。 | 在交错采纳的仓库面板上，要估的是采用者的平均效应；现有 DID 要求全对照池平行，而本面板处理前系数已经漂移。 |

English frame: "The problem is P. Existing work answers P only when A.
This project is about the case where A fails."

Chinese frame: 「要回答的问题是 P。已有工作只在 A 成立时回答 P。本文做 A
不成立的情形。」

## 2. Gap-organized literature (研究现状)

Group papers by the limitation that motivates the next section, not by
author or year. End the review on the gap the aims will close. One
limitation axis per paragraph.

Pattern: "Methods of type T assume A (cite, location). When A fails, as
in S, the retrieved works do not provide B."

中文：「T 类方法假定 A（出处）。A 在 S 中不成立时，按本次检索，还没有工作给出 B。」

A list that only summarizes paper 1, then paper 2, is a fail even if
the citations are real.

## 3. Numbered innovation points (创新点)

One point, one axis, one aim. Number them. Name the nearest prior work
and the axis (question, setting, method, data, or evidence). Cut generic
claims ("fills a gap", "has important value").

Pattern: "Innovation k (Aim k): relative to Work W, this project does X
on axis Y, so that Z becomes checkable."

中文：「创新点 k（对应研究内容 k）：相对 W，本课题在 Y 轴上做 X，使得 Z
在结题时可以核对。」

If two points share an axis, merge them.

## 4. Technical roadmap

A figure (study kit P2) or a short directed list: data or object in,
decisions in the middle, deliverable out. Each box is a verb plus object
("freeze panel", "define estimand", "run placebo"), not a course title
("literature review", "do experiments").

Expected by many panels even when the heading is not named. If the
school form omits it, fold the same sequence into 研究方案.

## 5. Milestones as deliverables

Months hold objects a panel could inspect, with a criterion that can
fail. Activities are not milestones.

| Activity (weak) | Deliverable (strong) |
|---|---|
| 查阅文献 / review literature | Retrieval memo: searches, date, whether Aim 1 already exists |
| 开展实验 / run experiments | Frozen panel + pre-registered placebo table, or "kill: weights collapse" |
| 撰写论文 / write papers | Chapter draft that reports a named estimand and its threats |

中文进度句：「第 M 月交付 D；成功当 C 成立；否则走备选 F。」

## 6. What not to write

- School page or character limits from memory.
- "First in the field" without a named retrieval.
- Innovation points that restate the topic in synonyms.
- A roadmap whose last box is "write the thesis" with no intermediate
  fail criterion.
