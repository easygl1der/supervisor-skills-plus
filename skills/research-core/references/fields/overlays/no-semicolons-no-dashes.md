# Overlay: no semicolons, no dashes

Optional. Switch on per project with `style.overlays: [no-semicolons-no-dashes]`
in `research.yaml`. Off by default because blanket punctuation bans push
generated prose into a new uniform texture (the same few connectors chained
everywhere). [src: note:n02§11.4; user:2026-10-13]

When on:

- No semicolons and no em-dashes in prose. Split the sentence or use a
  subordinate clause. [src: arc:CF-23@v2; skill:se-paper-refinement] (candidate)
- Vary the replacement: a full stop, "because", "so", "which", a relative
  clause, or a restructured sentence. Do not reuse one connector more than
  twice per paragraph. [src: note:n02§11.4] (candidate)
- Colons only before lists or definitions. [src: skill:se-paper-writing] (candidate)
- LaTeX en-dashes in number ranges (`1--3`) are allowed. [src: skill:avoid-ai-writing] (candidate)
