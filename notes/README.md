# Evidence notes

These notes are **loaded by citation** from `research-core` and other skills
(`note:nNN§…` in `[src:]` / `- Src:` lines). `scripts/check_sources.py`
requires `notes/NN-*.md` to exist for each `note:nNN` token.

| File | Role |
|---|---|
| `01-upstream-map.md` | Historical map of the included handbook and early skill procedures (cited by the AI/ML field profile). Not a claim that this repo is that project. |
| `02-local-skills-verdicts.md` | Verdicts on skills that were merged into this library. |
| `03-archive-map.md` | Citation formats for the private evidence archive (`arc:`). |
| `04`–`08` | Distilled process, writing, figure and checklist lessons from one anonymized empirical-SE project. |
| `10-reading-sources.md` | Licence-checked reading of third-party skills whose *ideas* were rewritten into `sv-quickread` / `sv-study`. |
| `11-learning-science-verified.md` | Verified learning-science sources for `sv-study`. |

Do not put private vault contents, personal names, or copyrighted PDFs here.
The evidence archive itself stays private (`$EVIDENCE_ARCHIVE`).
